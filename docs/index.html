Free tiers shrink quietly. This page watches them daily.

FreeTierWatch keeps the free-tier limits of 32 dev and AI services in one structured dataset, re-checks every provider's own pricing page each day, and publishes what changed — as JSON, RSS, and the ledger below.

Checked daily at 06:17 UTC

  • Download freetiers.json
  • Subscribe to the RSS feed
  • Read the source on GitHub

Current free-tier limits

Every number links back to the provider page it was read from, with the date we last verified it. Services with no free tier are listed too — knowing there isn't one is half the point.

Change ledger

Lines the daily check saw appear or disappear on a provider's pricing page. Confirmed quota changes are folded into the dataset; the git history of freetiers.json is the dated record.

Use the data

The dataset is CC BY 4.0 — build on it, credit FreeTierWatch.

# structured limits for all services
curl -s https://guillemmontejo.github.io/freetierwatch/data/freetiers.json

# everything the watcher has seen change
curl -s https://guillemmontejo.github.io/freetierwatch/data/changes.json

Want changes pushed to email or Slack instead? Add a thumbs-up to the alerts issue — enough interest and we build it.
